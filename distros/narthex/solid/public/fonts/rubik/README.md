# Rubik webfont assets

Vendored on 2026-09-29. The application serves these files from its own
origin; visitors make no Google Fonts request.

The unmodified WOFF2 files are the same Rubik v31 variable assets returned
by the previous Google Fonts stylesheet. Normal weights 300–900 and all
six previous script subsets are retained. Unicode ranges select only the
subsets used by the page; the document preloads the Latin subset.
