# Security

## Reporting a problem

Send an e-mail to contact@usefenel.com. Please include:

- what you found and where (file, page or address);
- the steps to reproduce it;
- what an attacker could do with it.

Please do not open a public issue for a security problem, and give us a
reasonable time to fix it before you make it public. We will answer as soon as
we can. There is no bug bounty.

## What is in scope

- The code in this repository.
- The website at https://usefenel.com and the demos it serves.

## What is out of scope

- Features this release does not support yet: running the API server with a
  database, accounts, payments and the Telegram bot. Reports about them are
  still welcome, but they are not deployed publicly.
- Problems in third-party packages. Please report those to their authors.
- Denial of service by sending a large amount of traffic.
